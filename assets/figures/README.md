# DDPO Figures

This directory contains the figures displayed in the repository’s main README.
Each figure is provided in two formats:

- **PNG:** browser-friendly preview embedded in the GitHub README.
- **PDF:** publication-quality vector version linked from the preview and caption.

The PNG previews were rendered from the corresponding source PDFs at a width
of 1800 pixels. The PDF files were copied without modification from the
authors’ manuscript assets.

When uploading the project to GitHub, preserve the repository-relative path
<code>assets/figures/</code>; the links in the root <code>README.md</code>
depend on this location.
